# 🚀 Startup Pitch Reviewer Voice Agent

An intelligent voice-based agent that listens to a user's startup pitch and provides **instant feedback** using **SWOT analysis** (Strengths, Weaknesses, Opportunities, Threats). Built using [Vapi.ai](https://vapi.ai), this agent simulates a **VC-style reviewer** and helps entrepreneurs refine their ideas through guided follow-up questions.

---

## 🎯 Features

- 🎙️ **Voice Input**: Users speak their startup idea directly to the agent.
- 📊 **SWOT Analysis**: The agent breaks the pitch down into strengths, weaknesses, opportunities, and threats.
- 🤖 **AI Feedback**: Personalized, structured advice using natural language understanding.
- 💡 **Follow-up Questions**: Helps refine the idea by prompting users with relevant, contextual questions.
- 🌐 **Built with Vapi.ai**: Leverages the powerful voice agent platform for real-time interactions.
